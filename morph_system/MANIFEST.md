# Included mechanisms

| MORPH concept | v0.1 implementation |
|---|---|
| Homeostasis field | Git/diff/dependency/public-surface vector + weighted fitness |
| Repository nervous system | lightweight import graph + decaying stress propagation |
| Counterfactual clones | isolated `git worktree` candidates with distinct causal hypotheses |
| Triple Battle Loop | Builder edits; Predator falsifies; Guardian protects homeostasis |
| Clonal selection | fitness-ranked candidates |
| Clonal evolution | winner-derived minimalize/harden/simplify offspring generation |
| Apoptosis | temporary worktree/branch deletion |
| Pheromone map | decaying per-file repair/risk signal memory |
| Failure antibodies | abstract diagnosis/strategy/verification memory, not copied patches |
| Hysteretic trust | fast trust loss, recovery only after repeated healthy outcomes |
| Compute metabolism | bounded clone/evolution counts and configurable verification budget |
| Predictive CI | v0.1 hooks/order foundation; no trained failure predictor yet |
| Failure dreams | not automatic in v0.1; use `predator_commands` for post-change adversarial probes |
