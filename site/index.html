purpose

Code that heals
before it breaks.

MORPH is a one-shot, multi-agent repair fabric for Claude Code and Codex. One invocation runs a full evolutionary lifecycle — sense the repo, grow independent repair candidates in isolated worktrees, battle-test them, select a winner by executable evidence, and exit.

Sense the repo

2grow

Grow candidates

3 causally distinct clones, each in its own git worktree, run Builder → Tests → Predator → Guardian.

3battle

Battle-test

The strongest clone reproduces — minimalized, hardened, simplified — and is tested again.

4select

Select the winner

6 repository states scored by fitness, checks, adversarial review, and compatibility review.

Apoptosis, then exit

Temp worktrees are force-deleted. Nothing is left running. The process exits.

why

Why one-shot, not a daemon

No background service watching your repo, no persistent process to trust indefinitely. MORPH runs, decides, and gets out of the way.

No daemon

A single invocation runs one full lifecycle, then exits. Nothing keeps listening on your machine between runs.

Zero dependencies

morph_system runs on the Python standard library alone — no third-party supply chain to audit before you run it.

Evidence, not vibes

A winner ships only if fitness, executed checks, Predator, and Guardian all clear their gates — every time.

gates

Six gates between a hypothesis and a merge

Every repair candidate is grown, reviewed, and scored before anything touches your working tree.

Multi-agent evolution

3 causally distinct clones battle in parallel each run — Builder, then Tests, then Predator, then Guardian.

Adversarial Predator review

A dedicated adversarial pass hunts for regressions and edge cases before a candidate can be selected.

Guardian compatibility gate

A second, independent reviewer blocks anything that breaks compatibility or blows up the blast radius.

Immune memory & pheromones

antibodies.json and pheromones.json carry decaying risk signal across runs — no daemon required to remember.

Git worktree isolation

Every candidate lives in its own throwaway git worktree clone. Apoptosis force-cleans them on exit.

Claude + Codex adapters

Drive the same lifecycle through claude -p or codex exec — or dry-run it with the built-in mock adapter.
